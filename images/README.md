# Dice Images Needed

Place 6 dice images in this folder with these exact names:

1. `dice1.png` - Shows 1 dot
2. `dice2.png` - Shows 2 dots
3. `dice3.png` - Shows 3 dots
4. `dice4.png` - Shows 4 dots
5. `dice5.png` - Shows 5 dots
6. `dice6.png` - Shows 6 dots

## Where to get dice images:

- **OpenGameArt.org** - Free game art
- **Flaticon.com** - Free icons (may require attribution)
- **Google Images** - Search "dice png" and filter for usage rights
- **Create your own** - Use any image editor

## Quick Test:

You can use any placeholder images for now (even just squares with numbers) to test the game functionality.

## Current Status:

⚠️ The game JavaScript is working correctly, but without these images, the dice won't display properly. The h3 result text should still update when you click "Roll the Dice!"
